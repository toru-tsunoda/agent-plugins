# glass-cockpit

AI に作業を任せている間に、進み具合を一目で見られる作業ダッシュボードです。飛行機のグラスコックピット（計器を1枚の画面にまとめた操縦席）のように、今の状態・タスク・費用を1画面に並べます。

## 背景

Claude Code に大きな作業を任せると、人には次のことが分かりにくくなります。

- 今、自分が何かすべき番なのか（質問や権限の確認で止まっていないか）
- 作業全体のうち、どこまで進んだのか
- 回答を待っている質問は無いか
- いくら使ったのか、無駄な動きをしていないか

ターミナルを遡れば分かりますが、並行してセッションを動かしていると追いきれません。glass-cockpit は、これらを1枚の画面にまとめます。

## このプラグインがやること

1. **タスクと質問を書き出す**: AI が作業をタスクに分け、着手・完了・行き詰まりのたびに `dashboard.json` を更新します。人の判断が要る時は質問を書き出し、回答が来ない時にどうするか（既定の行動）も添えます
2. **今の状態を出す**: 今のセッションが、人の回答待ち・権限の確認待ち・入力待ち・実行中のどれかを、色で出します。ブラウザのタブのタイトルにも出るので、別のタブを見ていても気づけます
3. **指標を集計する**: 費用（API 単価で換算）、キャッシュ読み込み率、ツールのエラー率などを、Claude Code のセッションログから集計します
4. **並行する作業を一覧にする**: 同じプロジェクトで動くセッションや、git worktree ごとの作業を一覧にします

## 前提条件

- **Node.js 22.18 以降**: スクリプトは TypeScript のまま Node.js で動きます。ビルドも依存パッケージも要りません
- **`.dev/` を `.gitignore` に入れておく**: ダッシュボードのファイルはコミットしない想定です

## 使い方

### 1. ダッシュボードを作る

作業を始める前に、Claude Code に「作業ダッシュボードを作って」と伝えます。

```bash
/glass-cockpit:dashboard
```

でも起動できます。プロジェクトに `.dev/glass-cockpit/` を作り、`dashboard.json` と料金表 `prices.json` を置きます。料金表は、Claude が公式の料金ページで最新にします（Web ページの取得の許可を求められることがあります）。

### 2. いつもどおり作業を頼む

あとは作業を頼むだけです。セッションを始めるたびに、フックが Claude にダッシュボードの更新を促します。

- Claude は、タスクに着手した時・終えた時・進めなくなった時に、タスクの状態を書き換えます
- 人の判断が要る時は、質問を書き出します。既定の行動で進められる時は、そのまま作業を続けます
- 質問には、チャットで答えてください。Claude が回答を書き込み、既定の行動と違えばやり直します

### 3. ダッシュボードを見る

「ダッシュボードを開いて」と伝えると、HTML を作ってブラウザで開きます。この HTML は開いた時点のままです。

常に最新で見たい時は、「ダッシュボードを serve で開いて」と伝えます。`http://127.0.0.1:8765` で配信し、30 秒ごとに集計し直します。この画面では、タスクを「やめる」ボタンで「やらない」に消し込めます。「やらない」にしたタスクは、Claude が着手しません。

### クラウドのセッションで見る

Claude Code on the web などクラウドのセッションでは、`serve` はコンテナの中の `127.0.0.1` で動くので、手元のブラウザから届きません。Claude Code のプロジェクト（共有フォルダ `/mnt/project-files/` があるセッション）なら、「クラウドでダッシュボードを見られるようにして」と伝えると、次の仕組みで最新の状態を見られます。

1. Claude が `dashboard.json` に `"cloud_view": true` を書きます（オプトイン。書かなければ何もしません）
2. フックが、今の状態が変わるたびに（続けて来た分は2秒まとめて）ダッシュボードの HTML を作り、共有フォルダの `glass-cockpit/<フォルダ名>/dashboard.html` に書き出します
3. Claude が、その HTML を読むだけのページを Artifact として公開します。開いた人自身の権限でファイルを読み、20 秒ごとに読み直します。URL は変わらないので、一度開けば最新の状態が出続けます

安全のため、次のようにしています。

- コンテナのポートを外に開けません（トンネルなども使いません）。開けると、認証なしでタスクや費用が見え、`serve` の書き込みの API で `dashboard.json` を書き換えられてしまうためです
- 新しい認証情報も使いません。読めるのは、そのプロジェクトのファイルを開ける人だけです。Artifact のページ自体はダッシュボードの中身を持たないので、リンクが渡っても、プロジェクトに入れない人には何も見えません
- 表示は読むだけです。タスクを「やめる」ボタンは出ません。読んだ HTML は、Artifact の機能に届かない sandbox の iframe に入れます
- コマンドは、説明が無い時に1行目が「直近のセッション」の行に出ます（`serve` や `build` と同じ）。秘密の値をコマンドに直接書かないでください

## 画面の見方

### ヘッダーの帯（今の状態）

| 色 | 表示 | 人がすること |
|---|---|---|
| 黄 | 質問に回答待ち・権限の確認待ち | すぐに答える・許可する |
| 青 | 入力待ち（ターン終了）・中断 | 結果を見て、次の指示を出す |
| 緑 | 実行中・応答を生成中 | 待つ（長く続くと黄・赤に変わる） |
| 赤 | API エラーで停止・止まっている可能性 | 様子を見に行く |
| 灰 | 終了 | 何もしない |

ほかにも動いているセッションがあれば、その件数も帯の最後に出ます（「ほかのセッション 権限待ち 1」）。

### 画面に並ぶもの

- **指標のタイル**: 費用、直近のセッションの費用、キャッシュ読み込み率、ツールのエラー率、文脈の読み落とし、自動続行、タスクの進み、未回答の質問
- **タスクと質問の表**: 進行中と次にやるものを上に出し、完了と「やらない」は折りたたみます。検索欄で絞り込めます
- **運用状況**（開閉できます）: サブエージェントや Codex の実行、使っているモデル、レビューゲート（作業の前に通したいスキルを実行したか）
- **セッション一覧**（開閉できます）: 直近 24 時間に動いたセッションの状態
- **worktree 一覧**（開閉できます）: git worktree ごとの費用・状態・タスク

費用の上限（`cost_cap_usd`・`session_cap_usd`）は、タイルのバーの目安です。上限を超えても作業は止まりません。

各指標の定義は [SKILL.md](skills/dashboard/SKILL.md#指標の意味) を参照してください。

## worktree ごとに分ける

親のリポジトリにダッシュボードがあれば、git worktree の中でセッションを始めた時に、その worktree 用のダッシュボードが自動でできます。費用の上限と料金表は親から引き継ぎ、タスクは空で始まります。PR のレビューや feature の開発を、worktree ごとに分けて見られます。親のダッシュボードは worktree の分を数えないので、費用が二重になりません。

## 作られるファイル

| 場所 | 中身 |
|---|---|
| `.dev/glass-cockpit/dashboard.json` | タスクと質問。Claude が書き換えます |
| `.dev/glass-cockpit/prices.json` | 料金表（モデルごとの単価） |
| `.dev/glass-cockpit/dashboard.html` | 表示用の HTML。手で編集しません |
| `.dev/glass-cockpit/viewer.html` | クラウドで見るための、Artifact 用のページ（`"cloud_view": true` の時だけ） |
| `/mnt/project-files/glass-cockpit/<フォルダ名>/dashboard.html` | クラウドで見るために書き出した HTML（`"cloud_view": true` の時だけ） |
| `~/.claude/glass-cockpit/sessions/<セッション ID>.jsonl` | フックが記録するセッションの出来事（今の状態の判定に使います） |

- フックは、ダッシュボードの無いプロジェクトも含め、プラグインを読み込んだすべてのセッションで記録します。`cleanupPeriodDays`（既定 30 日）より古い記録は消します
- 指標は、Claude Code が手元に残すセッションログを読んで集計します。集計した内容を外に送ることはありません（`"cloud_view": true` の時だけ、プロジェクトの共有フォルダに書き出します）。`serve` は、既定では自分の PC（`127.0.0.1`）からだけ開けます

`dashboard.json` の形式は [SKILL.md](skills/dashboard/SKILL.md#dashboardjson-の形式) を参照してください。

## うまく動かない時

### 画面が古いまま変わらない

- 「ダッシュボードを開いて」で開いた HTML は、開いた時点のままです。最新で見るには `serve` で開きます
- プラグインを更新した後は、動いている `serve` を止めて起動し直してください。起動し直すまで古い版のまま動きます
- クラウドで見ている Artifact は、セッションが動いた時にだけ書き出し直されます。Claude が入力を待っている間や、セッションが終わった後は、最後の状態のままです。上の帯に、集計した時刻が出ます

### タスクの表が今の作業と合っていない

「タスク」のタイルが黄色なら、Claude が作業した後に `dashboard.json` を更新していません。「ダッシュボードを更新して」と伝えてください。

### 閉じたセッションが「入力待ち」のまま残る

ターミナルで動かしたセッションは、閉じれば「終了」になります。VS Code の拡張やデスクトップアプリのセッション、プラグインを入れる前から動いていたセッションは、閉じたことが分からず「入力待ち」のまま残ることがあります。24 時間で一覧から消えます。

### 権限を許可したのに「権限の確認待ち」のまま

許可した後も、そのツールが終わるまでは「権限の確認待ち」と出ます。許可を知らせるフックが無いためです。

### 費用が請求額と違う

費用は、トークン数に API の単価を掛けた概算です。定額プランで使っていても API の単価で出します。料金表が古いと単価がずれるので、画面の右上の料金表の日付が古い時は「料金表を最新にして」と伝えてください。

## スクリプトを直接動かす

Claude に頼まずに動かす時は、ダッシュボードを置くプロジェクトのルートで実行します。スクリプトは、このフォルダの `skills/dashboard/scripts/dashboard.ts` です。

```bash
node <このフォルダ>/skills/dashboard/scripts/dashboard.ts init   # .dev/glass-cockpit/ に dashboard.json と prices.json を作る
node <このフォルダ>/skills/dashboard/scripts/dashboard.ts build  # .dev/glass-cockpit/dashboard.html を書き出す
node <このフォルダ>/skills/dashboard/scripts/dashboard.ts serve  # http://127.0.0.1:8765 で配信する
node <このフォルダ>/skills/dashboard/scripts/dashboard.ts export # クラウドで見るために、共有フォルダに書き出す（"cloud_view": true の時だけ）
node <このフォルダ>/skills/dashboard/scripts/dashboard.ts viewer # クラウドで見るための Artifact 用のページを .dev/glass-cockpit/viewer.html に書き出す
```

`serve` のポートが使われていれば、次の空いているポートを使います。
